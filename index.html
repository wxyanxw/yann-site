ABOUT THIS SIMULATION

一张轻量的机器人工作台。

用 Python 编写算法，在浏览器里观察关节、轨迹和力矩响应。

物理模型

自定义构型采用标准 DH：Rz(q+θ₀) Tz(d) Tx(a) Rx(α)；NERO 与上传构型使用源 URDF 的 origin、axis 和限位。圆润外壳仅用于显示，不改变关节变换或仿真几何。采用 120 Hz 固定步长、半隐式积分、对角关节惯量、重力、阻尼与 PD 驱动，并检测机械臂与地面的接触。

这是教学用简化动力学：不包含完整惯性耦合、自碰撞或真实硬件标定，不适合直接用于真实机械臂的安全验证。

任意轴数与运行方式

轴数输入支持任意正整数。较大模型按性能预算分配内存，3D 视图最多显示 128 个关节，所有已分配关节都参与控制。构型参数须完整定义后才能运行。超出内存预算会明确提示，不会静默截断接口。

Python 在独立 Web Worker 中通过 Pyodide 本地运行。代码自动存储在当前浏览器；停止按钮可终止计算。首次加载需要下载本站的 Python 运行资源。
